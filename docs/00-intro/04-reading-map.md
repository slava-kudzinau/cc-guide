## Choose Your Learning Path

### Path 1: "I want to use this daily" (Most Common)

**Goal**: Become productive with Claude Code in your daily workflow

**Time**: 2-3 hours total

**Recommended sequence:**

1. **[Section 01: Mental Models & Architecture](../01-fundamentals-core-concepts/01-mental-models.md)** (20 min)
   - Understand tools (CLI vs VS Code vs API)
   - Learn model selection (Sonnet vs Opus vs Haiku)
   - Skip for now: Extended thinking, MCP, Skills (read later when needed)

2. **[Section 02: Environment Setup](../01-fundamentals-core-concepts/02-environment-setup.md)** (30 min)
   - Full CLI installation & configuration
   - OR VS Code extension setup
   - Skip: AWS Bedrock, GCP Vertex (unless you need them)

3. **[Section 03: CLAUDE.md Guide](../01-fundamentals-core-concepts/03-claude-md-guide.md)** (20 min)
   - Create your project's CLAUDE.md file
   - Start with Level 1 template (5 minutes)
   - Iterate and improve over time

4. **[Section 05: Daily Workflows](../01-fundamentals-core-concepts/05-daily-workflows.md)** (60 min)
   - Morning routines
   - Feature development patterns
   - Code review workflows
   - Copy-paste and adapt to your needs

5. **[Prompt Library](../07-reference-troubleshooting/appendix-prompt-library.md)** (30 min)
   - Bookmark 10-20 prompts for your stack
   - Customize for your specific use cases

**Next**: After 1 week of daily use, explore [Part 2: Tools Mastery](../02-tools-mastery/) for automation
